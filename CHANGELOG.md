# Changelog

Все заметные изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.8.0] — 2026-11-14

### Добавлено
- **Синхронизированные тексты песен** на ПК и телефоне через открытую базу LRCLib: подсветка текущей строки, переход к моменту по нажатию, обычный текст и повтор поиска
- Задержка текста ±0,5 с с сохранением на устройстве
- Кнопка текста в десктопном плеере и горячая клавиша `L`; на телефоне — кнопка «Aa» рядом с треком
- Перемотка тапом по полосе прогресса в мобильном плеере
- Модульные тесты парсера LRC, нормализации запроса и выбора лучшего результата (39 тестов всего)

### Изменено
- Версия приложения обновлена до 1.8.0, Android versionCode/buildNumber — 6
- README дополнен разделом о текстах песен и новыми горячими клавишами

## [1.7.0] — 2026-11-09

### Добавлено
- Чтение тегов ID3/FLAC/MP4 для локальных файлов: название, исполнитель, альбом, год, длительность и обложка (`music-metadata`); обложки сохраняются в папку данных без дублей
- Библиотека, добавленная до 1.7.0, автоматически обогащается тегами при первом запуске
- Избранное: сердечко у каждого трека и в плеере, раздел «Любимое» со счётчиком
- Статистика прослушиваний: счётчики, время последнего воспроизведения, история (200 записей); лайки и статистика переживают повторный импорт
- Сортировка «По популярности» и «Недавно игравшие»
- Автообновление через GitHub Releases (`electron-updater`): фоновое скачивание, кнопка «Обновление готово» в заголовке окна
- Портативный режим: переменная окружения `SONOR_DATA_DIR` задаёт свою папку данных
- Первый запуск: онбординг с тремя сценариями старта и кнопки-действия в пустой библиотеке
- Тест-сьют `npm test` (30 тестов: парсеры плейлистов, санитайзеры библиотеки, помощники импортёров)
- CI: тесты и смоук-сборка на каждый push, автоматический релиз по тегу `v*`

### Исправлено
- Треки Spotify не игрались: Web API больше не отдаёт `preview_url` для новых приложений — превью теперь берётся с публичной embed-страницы трека с кэшем на сеанс
- PLS-плейлисты падали в JSON-парсер (детектор формата проверял JSON раньше PLS)
- XSPF-плейлисты крашились из-за опечатки в имени функции парсера
- Поиск свободной музыки зависал на 45+ секунд, если один каталог недоступен — теперь дедлайн 20 с на источник с понятным предупреждением
- `node_modules` не попадал в установщик: продакш-зависимости главного процесса (electron-updater, music-metadata) теперь включаются в пакет

### Изменено
- Мобильные зависимости (Expo, React Native) перенесены в `devDependencies` — в Windows-пакет попадает только рантайм десктопа (+0.5 МБ вместо сотен)
- Сырые ошибки VK API переведены в понятные действия (коды 5/15/17/20/27/28)
- OAuth-ошибки (`invalid_client`, `unauthorized_client`, `invalid_grant`) объясняют, что именно проверить

## [1.6.0] — 2026-11-09

### Добавлено
- Безопасная архитектура Electron: `contextIsolation`, изолированный preload-мост со строгим белым списком IPC-каналов, `sandbox`, без `nodeIntegration`
- Скрытое системное меню с рабочими Ctrl+C/Ctrl+V (раньше вставка токенов не работала)
- Один экземпляр приложения: повторный запуск показывает существующее окно
- Сохранение размера и положения окна между запусками
- Перемешивание и повтор (очередь/трек) с сохранением состояния, медиаклавиши (Media Session API), горячие клавиши (Space, ←/→, ↑/↓, M, S, R, Ctrl+F)
- Сортировка библиотеки, сохранение громкости и mute
- Автопереход на следующий трек при ошибке и один повтор со свежей ссылкой для Яндекса
- SVG-иконки, эквалайзер у играющего трека, кнопки «Слушать»/«Перемешать», анимации

### Исправлено
- Ошибочные уведомления не были выделены цветом (несовпадение класса toast)
- Ссылки Яндекса кэшировались и «умирали» между сессиями — теперь берутся свежими при каждом воспроизведении

## [1.5.1] и ранее
