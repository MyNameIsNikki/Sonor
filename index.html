⚿
Безопасный вход через OAuth

Пароль вводится только на сайте сервиса. Токен хранится зашифрованно на этом компьютере.

Каждый сервис требует своего приложения — один раз создайте его под своим аккаунтом:
VK — dev.vk.com → «Создать приложение», тип Standalone, включите право «Аудиозаписи», вставьте ID приложения.
Яндекс — oauth.yandex.ru → «Создать приложение», платформа «Веб-сервисы», доступ «Яндекс Музыка» (yamusic-grant), вставьте ClientID.
Spotify — developer.spotify.com/dashboard → Create app, Web API, Redirect URI http://127.0.0.1:53682/callback, вставьте Client ID.
Client ID не является секретом. Client Secret не нужен и не сохраняется.
