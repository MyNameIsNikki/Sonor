# Sonor — музыкальный плеер

Красивый музыкальный плеер в современной тёмно-синей теме: десктоп-приложение для Windows и мобильное приложение на Expo (Android / iOS). Поддерживает локальные аудиофайлы, импорт всей медиатеки из **VK Музыки**, **Яндекс Музыки** и **Spotify**, добавление музыки **без токена** по публичным ссылкам и легальные каталоги **Audius**, **ccMixter** и **Internet Archive**.

![Sonor](icon.png)

## Возможности

- 🎧 Воспроизведение локальных файлов: MP3, FLAC, WAV, M4A, OGG
- 💙 Премиальный тёмно-синий интерфейс: глубокий фон, циановые акценты, аккуратная типографика и плотные списки треков
- 📥 Импорт **всей медиатеки**: треки, плейлисты и альбомы из VK Музыки, Яндекс Музыки и Spotify
- 🔐 **Безопасный вход через OAuth**: Яндекс Device Flow на ПК и телефоне, VK и Spotify в браузере с вашим Client ID; пароль вводится только на сайте сервиса, токен хранится зашифрованно
- 🔓 Добавление **без токена** по публичной ссылке: Spotify, Яндекс Музыка, M3U/M3U8, PLS, XSPF и прямые аудиоссылки
- 📦 **Перенос плейлистов** из других сервисов и плееров: импорт M3U/M3U8/PLS/XSPF/CSV/JSON с прямыми аудиоссылками или локальными файлами
- 🌐 Раздел **«Свободная музыка»**: легальные каталоги Audius, ccMixter и Internet Archive — прослушивание и скачивание треков с открытыми лицензиями прямо в библиотеку
- 🔐 Опциональное запоминание токенов в зашифрованном хранилище, проверка токена и автоматическое обновление библиотеки при запуске
- 👤 Проверка подключения: приложение показывает имя аккаунта или понятную ошибку, если токен истёк
- 🗂️ Отдельные разделы «Плейлисты» и «Альбомы» с обложками и переходом к трекам коллекции
- 🔎 Поиск по названию, исполнителю и альбому
- ▶️ Полный плеер: play/pause, следующий/предыдущий, перемотка, громкость, автопереход
- 💾 Импортированная медиатека сохраняется между запусками; на телефоне локальные треки подхватываются автоматически, а свободная музыка и плейлисты из файлов доступны в мобильной версии
- 🖱️ Drag & drop файлов в окно приложения
- 📱 Адаптивный мобильный интерфейс (Expo, React Native)
- 🪟 Установщик Windows (NSIS) + портативный ZIP
- 🤖 Сборка Android APK через GitHub Actions

## Быстрый старт

```bash
npm install --legacy-peer-deps
npm start              # Expo dev server (телефон / веб)
npm run start:desktop  # Electron-приложение на компьютере
```

Требуется Node.js 18+ (проверено на Node 24).

## Сборка

### Windows

```bash
npm run build:windows
```

Результат:

- `release/Sonor-Setup-1.5.1.exe` — установщик с выбором папки, ярлыками на рабочем столе и в меню «Пуск»
- `release/Sonor Music Player-1.5.1-win.zip` — портативная версия
- `release/win-unpacked/` — распакованное приложение

Сборка не подписывается сертификатом (в конфиге `signAndEditExecutable: false`), поэтому Windows SmartScreen может показать предупреждение «Неизвестный издатель» — это нормально для неподписанных сборок. В метаданных файлов и установщика издатель указан как **ANV**; чтобы Windows показывала имя издателя без предупреждения, нужен платный сертификат подписи кода.

### Android

Вариант 1 — GitHub Actions (рекомендуется, Android SDK не нужен локально):

```
Actions → Build Android APK → Run workflow
```

Вариант 2 — локально (нужен Android SDK + JDK 17):

```bash
npx expo prebuild --platform android --clean
cd android
./gradlew assembleRelease
```

APK: `android/app/build/outputs/apk/release/app-release.apk`.

Вариант 3 — EAS Build:

```bash
npm run build:android
```

## Настройка импорта

Импорт работает по токенам доступа и загружает **всю медиатеку**, а не только первую страницу:

- **VK Музыка** — «Моя музыка» и все плейлисты;
- **Яндекс Музыка** — все плейлисты, «Мне нравится» и любимые альбомы;
- **Spotify** — все плейлисты, любимые треки и сохранённые альбомы.

Токены вводятся на вкладке «Импорт музыки». Перед импортом нажмите «Проверить» — Sonor покажет имя аккаунта или объяснит, почему токен не подошёл. По умолчанию включена галочка «Запоминать токены»: на ПК токены шифруются через системное хранилище Electron, на телефоне — через `expo-secure-store`. При следующем запуске Sonor сам обновляет сохранённые библиотеки; обновление можно запустить и вручную. Если галочку снять, токен действует только до закрытия приложения. Метаданные импортированных треков и коллекций сохраняются локально; ссылки на аудиопотоки сервисы выдают временно.

### Без токена

В блоке «Без токена — по ссылке» можно добавить:

- публичный **плейлист, альбом или трек Spotify** — через страницу embed, с доступными 30-секундными превью;
- публичный **плейлист или альбом Яндекс Музыки** — ссылки на поток получаются без авторизации;
- **M3U / M3U8 / PLS / XSPF** — сетевой плейлист, относительные ссылки разрешаются автоматически;
- **прямую аудиоссылку** на MP3, FLAC, WAV, M4A, OGG, AAC или OPUS.

Публичные ссылки VK Музыки без токена не поддерживаются: VK не отдаёт треки анонимно, для них нужен импорт с токеном.

Публичные ссылки Spotify работают, только если сервис доступен в вашей стране. При региональной блокировке (код 451) Sonor покажет понятное сообщение — используйте VPN или импорт с токеном.

### Безопасный вход через OAuth

Начиная с версии 1.5 Sonor умеет получать токены через официальный OAuth и **никогда не просит пароль от аккаунта**. Пароль вводится только на сайте сервиса, а токен сохраняется на компьютере в зашифрованном виде.

- **Яндекс Музыка** — Device Flow: нажмите «Войти через Яндекс», скопируйте код и подтвердите вход на `oauth.yandex.ru/device`. Client Secret не нужен. На телефоне доступен тот же вход; Client ID вводится в блоке «Настроить».
- **VK Музыка** — вход в отдельном окне VK OAuth. Нужен собственный Client ID Standalone-приложения с доступом `audio`.
- **Spotify** — OAuth PKCE в браузере. Нужен собственный Client ID; redirect URI должен совпадать с `http://127.0.0.1:53682/callback`. Client Secret не нужен.

Client ID не является секретом и вводится в блоке «Настроить» на вкладке импорта. Sonor не использует чужие Client ID, VK service key или перехват токенов из DevTools. Кнопка «Выйти» удаляет сохранённый токен. Ручной ввод токена остаётся запасным вариантом.

OAuth не обходит ограничения сервисов: VK может ограничивать `audio.get` для сторонних приложений, а токен Яндекса может не давать доступ к неофициальному Music API. Для публичных ссылок авторизация по-прежнему не требуется.

### Перенос плейлистов из VK / Яндекса

В блоке «Перенос плейлиста из VK / Яндекса» можно выбрать один или несколько файлов плейлистов, сохранённых другим плеером или сервисом. Поддерживаются форматы:

- **M3U / M3U8** — обычные и расширенные плейлисты с прямыми ссылками или путями к файлам;
- **PLS** — плейлисты Winamp;
- **XSPF** — открытый формат плейлистов;
- **CSV** — таблица с колонками названия, исполнителя, альбома, длительности и ссылки/пути;
- **JSON** — массив треков или объект с `tracks`, `items`, `songs`, `audios` или `entries`.

Важное условие: в файле должны быть **прямые аудиоадреса** или **локальные пути к аудиофайлам**. Если сервис экспортирует только названия треков и ссылки на страницы, такие строки будут пропущены — Sonor не подставляет вместо них чужие потоки и не обходит авторизацию VK или Яндекса.

На телефоне переносятся только **прямые https-ссылки на аудио**: локальные пути с компьютера внутри мобильного приложения недоступны.

Это перенос собственной медиатеки, а не обход ограничений сервисов. Для полного импорта VK Музыки и Яндекс Музыки используйте штатный импорт по токену — он загружает плейлисты и альбомы напрямую.

### Свободная музыка

В разделе «Свободная музыка» можно без токена искать и слушать треки из легальных каталогов с открытыми лицензиями:

- **Audius** — стриминг треков с открытыми лицензиями. Скачивание недоступно: сервис отдаёт только поток.
- **ccMixter** — музыка Creative Commons. Кнопка ↓ скачивает MP3 в папку `Музыка\Sonor` на ПК или во внутреннее хранилище приложения на телефоне и добавляет трек в библиотеку.
- **Internet Archive** — только аудиоколлекции с указанной лицензией. Файлы MP3, OGG и FLAC скачиваются в ту же папку.

Скачанные треки сохраняются на диск и остаются в библиотеке после перезапуска. Лицензия показана в строке результата: перед публичным использованием проверьте её условия, некоторые лицензии разрешают только некоммерческое использование.

Раздел доступен и на ПК, и в мобильной версии. На телефоне скачанные файлы хранятся во внутреннем хранилище приложения.

Sonor не обходит DRM и ограничения платных сервисов. Для VK Музыки, Яндекс Музыки и Spotify по-прежнему нужен легальный доступ и токен.

### VK Музыка

1. Откройте [vk.com/editapp](https://vk.com/editapp) и создайте Standalone-приложение.
2. Получите access token с правами `audio`.
3. Вставьте токен в поле VK.

> VK ограничивает `audio.get` для сторонних приложений — если API вернёт ошибку доступа, используйте официальный токен приложения VK.

### Яндекс Музыка

1. Зарегистрируйте приложение на [oauth.yandex.ru](https://oauth.yandex.ru/).
2. Получите OAuth-токен с доступом к музыке.
3. Вставьте токен в поле Яндекс.

Ссылки на треки Яндекс Музыки выдаются по запросу в момент воспроизведения. Если токен сохранён в зашифрованном хранилище, он восстанавливается при запуске и треки играют без повторного ввода. Для публичных ссылок токен не нужен.

### Spotify

1. Создайте приложение на [developer.spotify.com](https://developer.spotify.com/dashboard).
2. Получите access token (scopes: `playlist-read-private`, `user-library-read`).
3. Вставьте токен в поле Spotify.

Spotify отдаёт только 30-секундные `preview_url` для части треков, а для многих треков превью отсутствует вовсе. Sonor импортирует метаданные, обложки и доступные превью; полноценное воспроизведение требует Spotify Premium и SDK.

## Решение проблем

- **`npm install` падает с peer dependency** — используйте `npm install --legacy-peer-deps`.
- **Windows SmartScreen** — установщик не подписан, нажмите «Подробнее → Выполнить в любом случае».
- **Пустое окно Electron** — запустите `npm run start:desktop`; в dev-режиме приложение ждёт Expo на `localhost:19006`.
- **Импорт не работает** — нажмите «Проверить» рядом с полем токена: Sonor покажет имя аккаунта или точную причину ошибки. Проверьте срок жизни токена и необходимые scopes.
- **После перезапуска пропали треки** — начиная с версии 1.2 локальные файлы сохраняются вместе с путём к файлу, а библиотека хранится в стабильной папке `%APPDATA%\\Sonor` (данные из старых папок переносятся автоматически). Если файл был перемещён или удалён, трек останется в списке, но не сможет играть.
- **Плейлисты или альбомы не появились** — часть коллекций может быть недоступна токену; импорт продолжается, а предупреждения показываются после завершения.
- **Трек не играет** — у трека может не быть прямой ссылки (особенно Spotify/VK), либо ссылка сервиса устарела. Импортируйте медиатеку заново, обновите сохранённую библиотеку или добавьте локальный файл.
- **Ссылка VK не импортируется без токена** — это ограничение VK: анонимный доступ к трекам закрыт. Используйте импорт с токеном.
- **Токен не запомнился на телефоне** — проверьте, что на устройстве доступен `expo-secure-store`; без него токен действует только до закрытия приложения.
- **Публичная ссылка Spotify без превью** — часть треков не имеет 30-секундного `preview_url`, такие строки импортируются без воспроизведения.
- **Плейлист на телефоне не импортируется** — мобильная версия принимает только прямые https-ссылки на аудио. Ссылки на страницы VK/Яндекса и локальные пути с компьютера пропускаются.
- **Свободная музыка не находится** — проверьте интернет. Источники независимы: если один каталог недоступен, остальные продолжают работать. Audius доступен только для прослушивания, скачивание поддерживают ccMixter и Internet Archive.
- **Плейлист импортировался пустым** — в файле нет прямых аудиоссылок или существующих локальных файлов. Экспорт одного списка названий недостаточен; используйте импорт по токену или добавьте файлы вручную.
