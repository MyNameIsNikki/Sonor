# Sonor — музыкальный плеер

Красивый музыкальный плеер в сине-голубой неоновой теме: десктоп-приложение для Windows и мобильное приложение на Expo (Android / iOS). Поддерживает локальные аудиофайлы, импорт всей медиатеки из **VK Музыки**, **Яндекс Музыки** и **Spotify**, а также добавление музыки **без токена** по публичным ссылкам.

![Sonor](icon.png)

## Возможности

- 🎧 Воспроизведение локальных файлов: MP3, FLAC, WAV, M4A, OGG
- 💙 Премиальный дизайн: glassmorphism, градиенты, неоновый циан `#00d4ff`
- 📥 Импорт **всей медиатеки**: треки, плейлисты и альбомы из VK Музыки, Яндекс Музыки и Spotify
- 🔓 Добавление **без токена** по публичной ссылке: Spotify, Яндекс Музыка, M3U/M3U8, PLS, XSPF и прямые аудиоссылки
- 🔐 Опциональное запоминание токенов в зашифрованном хранилище и автоматическое обновление библиотеки при запуске
- 🗂️ Отдельные разделы «Плейлисты» и «Альбомы» с обложками и переходом к трекам коллекции
- 🔎 Поиск по названию, исполнителю и альбому
- ▶️ Полный плеер: play/pause, следующий/предыдущий, перемотка, громкость, автопереход
- 💾 Импортированная медиатека сохраняется между запусками; на телефоне локальные треки подхватываются автоматически, на ПК файлы добавляются кнопкой или перетаскиванием
- 🖱️ Drag & drop файлов в окно приложения
- 📱 Адаптивный мобильный интерфейс (Expo, React Native)
- 🪟 Установщик Windows (NSIS) + портативный ZIP
- 🤖 Сборка Android APK через GitHub Actions

> Для телефонов собирается **APK** (Android) — формат установочного файла для мобильных. `.exe` — это формат Windows, на телефоне он не запускается.

### GitHub Actions

- **Build Android APK** — `Actions → Build Android APK → Run workflow`. Готовый APK появится в артефактах workflow (`sonor-apk`).
- **Build Windows Installer** — `Actions → Build Windows Installer → Run workflow`. Установщик и ZIP появятся в артефактах (`sonor-windows-setup`).

## Быстрый старт

```bash
npm install --legacy-peer-deps
npm start              # Expo dev server (телефон / веб)
npm run start:desktop  # Electron-приложение на компьютере
```

Требуется Node.js 18+ (проверено на Node 24).

## Сборка

### Windows

```bash
npm run build:windows
```

Результат:

- `release/Sonor-Setup-1.2.0.exe` — установщик с выбором папки, ярлыками на рабочем столе и в меню «Пуск»
- `release/Sonor Music Player-1.2.0-win.zip` — портативная версия
- `release/win-unpacked/` — распакованное приложение

Сборка не подписывается сертификатом (в конфиге `signAndEditExecutable: false`), поэтому Windows SmartScreen может показать предупреждение «Неизвестный издатель» — это нормально для неподписанных сборок.

### Android

Вариант 1 — GitHub Actions (рекомендуется, Android SDK не нужен локально):

```
Actions → Build Android APK → Run workflow
```

Вариант 2 — локально (нужен Android SDK + JDK 17):

```bash
npx expo prebuild --platform android --clean
cd android
./gradlew assembleRelease
```

APK: `android/app/build/outputs/apk/release/app-release.apk`.

Вариант 3 — EAS Build:

```bash
npm run build:android
```

## Настройка импорта

Импорт работает по токенам доступа и загружает **всю медиатеку**, а не только первую страницу:

- **VK Музыка** — «Моя музыка» и все плейлисты;
- **Яндекс Музыка** — все плейлисты, «Мне нравится» и любимые альбомы;
- **Spotify** — все плейлисты, любимые треки и сохранённые альбомы.

Токены вводятся на вкладке «Импорт музыки». По умолчанию включена галочка «Запоминать токены»: на ПК токены шифруются через системное хранилище Electron, на телефоне — через `expo-secure-store`. При следующем запуске Sonor сам обновляет сохранённые библиотеки; обновление можно запустить и вручную. Если галочку снять, токен действует только до закрытия приложения. Метаданные импортированных треков и коллекций сохраняются локально; ссылки на аудиопотоки сервисы выдают временно.

### Без токена

В блоке «Без токена — по ссылке» можно добавить:

- публичный **плейлист, альбом или трек Spotify** — через страницу embed, с доступными 30-секундными превью;
- публичный **плейлист или альбом Яндекс Музыки** — ссылки на поток получаются без авторизации;
- **M3U / M3U8 / PLS / XSPF** — сетевой плейлист, относительные ссылки разрешаются автоматически;
- **прямую аудиоссылку** на MP3, FLAC, WAV, M4A, OGG, AAC или OPUS.

Публичные ссылки VK Музыки без токена не поддерживаются: VK не отдаёт треки анонимно, для них нужен импорт с токеном.

Полноценный вход через браузер (OAuth) в этой версии не встроен: для него нужны собственные зарегистрированные Client ID/Secret приложений VK, Яндекса и Spotify. Sonor не использует чужие публичные ключи.

### VK Музыка

1. Откройте [vk.com/editapp](https://vk.com/editapp) и создайте Standalone-приложение.
2. Получите access token с правами `audio`.
3. Вставьте токен в поле VK.

> VK ограничивает `audio.get` для сторонних приложений — если API вернёт ошибку доступа, используйте официальный токен приложения VK.

### Яндекс Музыка

1. Зарегистрируйте приложение на [oauth.yandex.ru](https://oauth.yandex.ru/).
2. Получите OAuth-токен с доступом к музыке.
3. Вставьте токен в поле Яндекс.

Ссылки на треки Яндекс Музыки выдаются по запросу в момент воспроизведения. Если токен сохранён в зашифрованном хранилище, он восстанавливается при запуске и треки играют без повторного ввода. Для публичных ссылок токен не нужен.

### Spotify

1. Создайте приложение на [developer.spotify.com](https://developer.spotify.com/dashboard).
2. Получите access token (scopes: `playlist-read-private`, `user-library-read`).
3. Вставьте токен в поле Spotify.

Spotify отдаёт только 30-секундные `preview_url` для части треков, а для многих треков превью отсутствует вовсе. Sonor импортирует метаданные, обложки и доступные превью; полноценное воспроизведение требует Spotify Premium и SDK.

## Решение проблем

- **`npm install` падает с peer dependency** — используйте `npm install --legacy-peer-deps`.
- **Windows SmartScreen** — установщик не подписан, нажмите «Подробнее → Выполнить в любом случае».
- **Пустое окно Electron** — запустите `npm run start:desktop`; в dev-режиме приложение ждёт Expo на `localhost:19006`.
- **Импорт не работает** — проверьте срок жизни токена и необходимые scopes.
- **Плейлисты или альбомы не появились** — часть коллекций может быть недоступна токену; импорт продолжается, а предупреждения показываются после завершения.
- **Трек не играет** — у трека может не быть прямой ссылки (особенно Spotify/VK), либо ссылка сервиса устарела. Импортируйте медиатеку заново, обновите сохранённую библиотеку или добавьте локальный файл.
- **Ссылка VK не импортируется без токена** — это ограничение VK: анонимный доступ к трекам закрыт. Используйте импорт с токеном.
- **Токен не запомнился на телефоне** — проверьте, что на устройстве доступен `expo-secure-store`; без него токен действует только до закрытия приложения.
- **Публичная ссылка Spotify без превью** — часть треков не имеет 30-секундного `preview_url`, такие строки импортируются без воспроизведения.
